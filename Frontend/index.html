Simple monitoring

What does Veyra actually check?

You don't need to understand servers or networking to use Veyra. It checks the important parts of a website and turns the results into simple information.

1

Availability

Veyra connects to your website to see whether it can be reached.

2

HTTP status

It checks the server response such as 200, 404 or 500.

3

Response time

Veyra measures how long the website takes to respond.

4

SSL security

It checks whether HTTPS is valid and how many days remain before the certificate expires.

Why retries?

A single failed request does not always mean that a website is actually down. Veyra can retry the check before creating an incident, reducing false alarms.
